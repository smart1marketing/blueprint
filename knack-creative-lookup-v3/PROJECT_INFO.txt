REQUIRED ENVIRONMENT VARIABLES:

1. REACT_APP_KNACK_API_KEY
   Where: Knack Settings > API & Webhooks
   Format: 32+ character string

2. REACT_APP_KNACK_APP_ID (NEW!)
   Where: Your Knack builder URL
   Format: 15+ character string
   Example: https://builder.knack.com/app/[THIS_PART]/...

3. REACT_APP_KNACK_IO_OBJECT_ID
   Value: object_234
