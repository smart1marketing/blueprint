SERVICE TYPE: Web Service
RUNTIME: Node
BUILD COMMAND: npm install && npm run build
START COMMAND: npm start

ENVIRONMENT VARIABLES (3 REQUIRED):
  REACT_APP_KNACK_API_KEY = your_api_key_here
  REACT_APP_KNACK_APP_ID = your_application_id_here
  REACT_APP_KNACK_IO_OBJECT_ID = object_234
  NODE_ENV = production

AUTO-DEPLOY: Yes (watches GitHub main branch)

═══════════════════════════════════════════════════════════════

HOW TO FIND YOUR VALUES:

API Key:
  1. Knack App Settings > API & Webhooks
  2. Copy REST API Key
  3. Should be 32+ characters

Application ID:
  1. Look at your Knack builder URL:
     https://builder.knack.com/app/[APPLICATION_ID]/...
  2. Copy the ID between /app/ and /data

Object ID:
  1. Should be: object_234 (for Insertion Orders)

═══════════════════════════════════════════════════════════════

STEPS:
1. Go to render.com
2. Click "New +" → "Web Service"
3. Connect GitHub repository
4. Set Build & Start commands above
5. Add Environment Variables (3 of them!)
6. Click "Deploy"
7. Wait 2-5 minutes
8. Your app is live! ✨
