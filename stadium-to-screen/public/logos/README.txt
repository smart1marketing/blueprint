Drop official brand SVGs here, named after the domain used in BRAND_DOMAINS
(inside public/index.html), e.g.:

  public/logos/hulu.com.svg
  public/logos/spotify.com.svg
  public/logos/espn.com.svg

The tool tries this folder first. Anything here is used forever and works
offline; anything missing falls back to a logo CDN, then a favicon, then a
coloured monogram — so a logo box is never empty.
